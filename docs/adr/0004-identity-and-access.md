# ADR 0004：管理员密码建房、随机邀请令牌加入、独立的玩家会话令牌

状态：已采纳（2026-11-13）

## 决定

- 创建房间需要实例管理员密码（`ADMIN_PASSWORD`），创建者成为房主。部署者可同时是管理员和房主，但两种权限分开判定。
- 邀请链接 `/join/<token>`，令牌为 192 bit 随机值。加入只需昵称。
- 加入成功后签发独立的玩家会话令牌：浏览器存于 localStorage，服务端只存 SHA-256；实时连接用它鉴权。昵称不参与任何权限或身份判定。
- 加入页在成功后用房间地址替换历史记录，邀请令牌不停留在地址栏；页面设置 `no-referrer`。
- 建房与加入接口按 IP 限速；每房间最多 8 名成员（加入事务内加行锁保证）。

## 理由与取舍

- 不要求注册、不用密码，符合 OPS-01/02；自部署实例默认不允许陌生人建房。
- 会话令牌放 localStorage 而非 HttpOnly Cookie：实时连接与测试客户端都能显式携带，也便于同一浏览器在多个房间持有不同身份。代价是 XSS 可读取令牌——当前页面不渲染任何 HTML 富文本（聊天按纯文本输出），风险可控；若将来引入富文本内容需重新评估。
- 邀请令牌目前明文存库，以便房主随时重新复制链接；它可轮换，泄露影响仅限新成员加入。

## 后续（PRD 已要求但尚未实现）

- 邀请的撤销/轮换入口、移除成员、房主离线时由管理员恢复控制（PRD §10.2 待定）。
- 更换设备后的人工身份恢复方式（PRD §8.3 待定）。
