# 数牌拆拼（meld）— 规则规格

方向：数字牌拼顺子和刻子、可以把整桌牌拆开重拼的出清游戏（机制参考：「数字牌拉密」一类的桌游）。名称、文案为本项目自定。实现：`packages/games/src/meld/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 2–4 人 |
| 内容 | 不使用题库，不调用模型 |
| 设置 | `turnSeconds` 每回合时限（默认 0 = 不限时） |
| 牌 | 4 种颜色（红、蓝、黄、黑）× 1–13 × 2 张 = 104 张，加 2 张百搭，共 106 张 |
| 手牌 | 每人 14 张，其余为牌堆 |
| 顺子 | 同一种颜色、数字相连，至少 3 张，最多 13 张；1 不能接在 13 后面 |
| 刻子 | 同一个数字、颜色各不相同，3 或 4 张 |
| 百搭 | 可以当任何一张。顺子里先补中间的空，多出来的接在大的一头，到 13 了再接小的一头 |
| 回合 | 二选一：出牌；或者摸一张牌，回合结束 |
| 第一次出牌 | 只能用自己手里的牌另起几组，合计至少 30 点（百搭按它顶替的数字算）；这之前不能动桌上的牌，也不能往桌上的组里加牌 |
| 之后出牌 | 可以随意拆开、重组桌上所有的牌。要求：回合结束时桌上每一组都成立；原来在桌上的牌一张不少；至少出了一张自己的牌 |
| 提交方式 | 客户端在本地摆好，一次提交「整张桌面」；服务端从头校验，不信任客户端的判断 |
| 结束 | 有人出完手牌，立即结束，他获胜。牌堆摸完后「摸牌」变成「过」；所有人接连都过，则手牌点数最少的人获胜（百搭算 30 点，并列都算） |
| 秘密信息 | 手牌只发给本人，别人只看得到张数；牌的 id 是洗牌后的序号，不含牌面信息；牌堆不发给任何人。结束后公开全部手牌 |
| 计分 | 获胜 +3；三人以上时，其余人里手牌点数最少的 +1 |
| 超时 | 视为摸一张牌（牌堆空了则视为过）；正在摆的牌不算数 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 不支持，下一场加入 |

## 与原型不同

- **百搭可以直接挪走。** 原型要求先用一张真牌把桌上的百搭换下来，而且换下来的百搭必须当回合用掉。这里把百搭当成普通的牌：只要最后每一组都成立，它可以被拆到别的组里。
- **一张数字牌加两张百搭**既能看成顺子也能看成刻子，按点数高的那种算。
- **摸牌不罚分。** 原型的计分是输家按剩余点数扣分、赢家得到这些分数的总和，打多局累计。这里一局就是一场，只给名次分。
- **没有「摆不回去就罚三张」**：不成立的桌面根本提交不上去，超时就是摸一张。

## 界面

点牌选中（手里的和桌上的都可以，可多选），再点某一组后面的「放这」或「另起一组」。不成立的组用红色虚线框出来，出牌按钮上写着还差什么。「帮我找现成的组」只会从手牌里找不含百搭的现成三张，不会替你拆桌上的牌。

**待确认的默认值**：第一次出牌的门槛（30 点）；每回合时限默认不限（原型通常限一到两分钟）；名次分的档位。
