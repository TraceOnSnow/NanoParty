# 翻牌诈唬（skull）— 规则规格

方向：暗叠诈唬喊价（机制参考：「花与骷髅」类的暗牌喊价玩法）。名称、文案为本项目自定。实现：`packages/games/src/skull/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–8 人 |
| 内容 | 不使用题库，不调用模型 |
| 设置 | `turnSeconds` 每步时限（默认 0 = 不限时） |
| 配件 | 每人 3 朵花 + 1 个骷髅 |
| 开局 | 每轮所有人同时暗放一张到自己面前 |
| 轮流 | 轮到的人：再往自己那叠上加一张，或开始喊价（「我能翻 N 朵花」）。手里没牌可加时必须喊价 |
| 喊价 | 之后依次加价或放弃；喊到等于桌上总张数，或其他人都放弃时，最高喊价者成为挑战者 |
| 翻牌 | 挑战者必须先从上到下翻完自己那叠，再任选别人的叠从顶上一张张翻 |
| 判定 | 翻够 N 朵花 → 挑战成功，记 1 胜；翻到骷髅 → 失败，随机永久失去自己的一张牌，牌全没了就出局 |
| 获胜 | 先拿到 2 胜的人，或其他人全部出局时剩下的那个人 |
| 秘密信息 | 每叠的内容只有主人可见；每人还剩几张公开，但具体是花还是骷髅不公开 |
| 计分 | 赢家 +3 |
| 超时 | 轮流阶段自动喊 1；喊价阶段自动放弃；翻牌阶段自动翻第一叠可翻的牌 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 不支持，下一次开始游戏时加入 |

**待确认的默认值**：失败时失去的牌是随机的（另一种做法：翻到别人的骷髅时由对方挑）。
