# 黑暗料理（dish）— 规则规格

方向：一对一递牌说谎（机制参考：「扣着递一张牌并声称它是什么，对方猜真假或偷看后转手」的诈唬卡牌）。名称、牌面种类、文案为本项目自定。实现：`packages/games/src/dish/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 2–6 人 |
| 内容 | 不使用题库，不调用模型 |
| 设置 | `games` 局数（默认 1）；`turnSeconds` 每步时限（默认 0 = 不限时） |
| 牌 | 8 种 × 8 张 = 64 张，全部发完（人数除不尽时前几位多一张） |
| 开始一次递牌 | 轮到的人从手里选一张，扣着推给任意一位其他玩家，并声称它是 8 种里的哪一种（可以说谎） |
| 收到牌的人 | 二选一。判断：说「是真的」或「在骗人」，然后翻开——判断正确，牌放到**声称者**面前；判断错误，牌放到自己面前。或者偷看：看完必须推给一位还没看过这张牌的人，并重新声称（可以和上家不同）；之后由新的人面对同样的选择，此时的声称者是刚转手的人 |
| 没人可推 | 所有其他人都看过这张牌时，面前的人只能判断 |
| 下一次 | 牌落在谁面前，就由谁开始下一次递牌 |
| 输 | 面前有 4 张同一种的人输；或者轮到自己开始却没有手牌的人输。一局只有一个输家 |
| 秘密信息 | 手牌只发给本人（别人只看到张数）；递出的牌只发给看过它的人；面前的牌公开 |
| 计分 | 每局输家以外的人各 +1 |
| 超时 | 该开始的人把第一张手牌如实推给下家；该判断的人自动判「是真的」；偷看后的人原样转给第一位没看过的人 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 下一局加入 |

**待确认的默认值**：给分口径（只有一个输家，没有赢家）；是否加入原型的进阶变体。
