# 谁最可能（mostlikely）— 规则规格

首发游戏之一，方向：熟人判断投票。名称、内容与分值为本项目自定，不使用任何商业作品的名称或素材。实现：`packages/games/src/mostlikely/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–8 人，个人计分 |
| 内容 | 题库类型 `who-prompt`：一句「谁最可能……」的通用情境，不涉及真实个人经历 |
| 设置 | `rounds`（默认 8）；`voteSeconds`（默认 45） |
| 选题 | 每轮正式开始前，由轮流担任的出题人从 3 道候选里选一道；可以不限次数地换一批，或自己出一道（保存进题库，来源记为玩家自拟）。换一批不消耗题库，只有确认的题才计为已用；选题阶段不算回合开始，不能投票跳过。AI 交来的候选题会替换当前候选，若本轮已开始则留到下一轮。选题时限 `pickSeconds`（默认 60 秒），超时用第一道候选。出题人也照常参与本轮 |
| 秘密信息 | 各人的投票在揭晓前不公开；谁已投票是公开的 |
| 投票 | 每人投一位本轮玩家（可以投自己），不可修改 |
| 揭晓 | 全部投完、超时或房主提前揭晓后，公开谁投了谁 |
| 计分 | 投给得票最多者（并列都算）的玩家各 +1 |
| 跳过 | 投票阶段可投票跳过，不计分 |
| 中途加入 | 从下一轮开始参与；等待期间看不到秘密信息 |
| 断线 | 身份与已提交内容保留；每个阶段都有超时或房主推进入口，不会被离线玩家卡住 |
| 重启恢复 | 游戏段暂停，房主继续后当前阶段计时重新开始；已发的秘密和已提交内容不变 |
| 过期操作 | 每个动作携带阶段计数 `step`，阶段一变旧动作即失效 |

**待确认的默认值**：计分方式（目前奖励「和大家想的一样」）；是否完全不计分、只看结果。
