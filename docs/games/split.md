# 五五开（split）— 规则规格

方向：两难情境与意见分裂（机制参考：编写让大家意见对半开的情境的玩法）。名称、题目与计分为本项目自定。实现：`packages/games/src/split/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–8 人 |
| 内容 | 题库类型 `split-prompt`：恰好含一个「____」的两难题，可自定两个选项文字（默认「愿意 / 不愿意」） |
| 设置 | `rounds`（默认 3）；`writeSeconds`（默认 90）；`voteSeconds`（默认 90）；`pickSeconds`（默认 60） |
| 选题 | 轮流的出题人从候选里选，或自己出一道 |
| 填空 | 所有人同时填空（≤30 字），提交前互不可见 |
| 表态 | 公开所有版本（显示作者），每人对每个别人的版本选两个选项之一，一次性提交；提交前他人看不到 |
| 计分 | 每个版本：作者得 回答人数 − \|甲 − 乙\|。完美对半得分最高，一边倒得 0 |
| 超时 / 房主推进 | 用已收到的内容进入下一阶段 |
| 跳过 / 加入 / 恢复 | 同其它内容游戏 |

**待确认的默认值**：表态是否匿名（目前朋友局不匿名）；计分公式。
