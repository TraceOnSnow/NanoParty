# 问出秘密词（wordhunt）— 规则规格

方向：限时是非问答猜词 + 隐藏身份（机制参考：由主持人回答问题、狼人与预言家也知道秘密词的玩法）。名称与规则表述为本项目自定。实现：`packages/games/src/wordhunt/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 4–8 人 |
| 内容 | 题库类型 `guess-word`（与「不撞词」共用） |
| 设置 | `rounds`（默认 3）；`askSeconds` 提问时限（默认 240）；`voteSeconds` 指认时限（默认 90）；`pickSeconds`（默认 60） |
| 村长 | 每轮一名玩家轮流担任，属于村民阵营；从候选里选词或自己出，**候选只有村长能看到** |
| 身份 | 村长以外随机：狼人 1 名（村长以外 ≥6 人时 2 名）、预言家 1 名，其余村民。身份只有本人知道；狼人互相知道 |
| 秘密词 | 村长、狼人、预言家知道；村民在揭晓前看不到 |
| 提问 | 非村长提问，村长回答「是 / 不是 / 也许 / 很接近 / 差得远」，或判「就是它」；每人同时只能有一条在等回答 |
| 猜词 | 非村长可随时直接猜，规范化后与秘密词相同即猜中；猜错会记为一条「不是」 |
| 猜中后 | 狼人指认谁是预言家（第一个提交的狼人决定）：指认对 → 狼人赢，否则村民赢。期间不公开哪位狼人在操作 |
| 时间到 | 所有人投票指认狼人：票数最多且唯一的是狼人 → 村民赢，否则狼人赢 |
| 计分 | 获胜阵营每人 +3 |
| 跳过 / 加入 / 恢复 | 提问阶段可投票跳过（身份与词重新发）；中途加入下一轮参与 |

**与参考玩法的差异**：村长没有隐藏身份；没有回答次数限制。**AI 村长（未实现）**：同海龟汤，需要真实模型验证并另行批准。

**待确认的默认值**：狼人人数分档；村长是否也抽身份；是否限制回答次数。
