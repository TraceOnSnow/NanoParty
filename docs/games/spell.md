# 盲念咒语（spell）— 规则规格

方向：只有自己看不到自己的石头，靠别人面前的石头推理（机制参考：「喊咒语数字、喊错掉血」的推理桌游）。名称、咒语名、文案为本项目自定。实现：`packages/games/src/spell/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 2–5 人 |
| 内容 | 不使用题库，不调用模型 |
| 设置 | `target` 目标分（默认 8）；`turnSeconds` 每步时限（默认 0 = 不限时） |
| 石头 | 36 块：数字 n 有 n 块（1–8）。每轮洗匀后暗置 4 块秘密石；2 人局公开 12 块、3 人局公开 6 块到桌面；每人面前 5 块；其余为牌堆 |
| 生命 | 每人 6 点，上限 6 |
| 回合 | 喊一个数字。面前有这块石头：移到桌面（公开），发动咒语，然后可以继续喊**不小于**它的数字，或收手。面前没有：掉 1 点生命（喊 1 喊错则掷骰掉血），回合结束。回合结束时从牌堆补到 5 块（牌堆不够就有多少补多少） |
| 咒语 | 1：掷骰（1–3），其他人各掉这么多。2：其他人各掉 1，自己回 1。3：掷骰，自己回这么多。4：拿走一块秘密石，只有自己知道数字。5：上家和下家各掉 1。6：下家掉 1。7：上家掉 1。8：自己回 1 |
| 上家 / 下家 | 下家是行动顺序里的下一个人，上家是前一个人。2 人局上家和下家是同一个人，咒语 5 只掉 1 点 |
| 一轮结束 | 有人生命归零；或有人把面前的石头全部喊完（此时其他人全部归零） |
| 每轮得分 | 活着的人各 1 分；结束这一轮且自己活着的人改得 3 分；活着的人每拿过一块秘密石再 +1 |
| 结束 | 一轮结算后有人达到目标分，分数最高的人赢 |
| 秘密信息 | 自己面前的石头不发给自己（只发数量）；牌堆和秘密石不发给任何人；拿到的秘密石只发给拿的人，别人只看到数量。一轮结束后自己的石头才公开 |
| 计分 | 赢家 +3（并列都得） |
| 超时 | 已经喊中过就收手；否则替 TA 喊 8 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 下一轮加入 |

与原型不同或自行确定的地方：

- 骰子点数取 1–3（查到的规则介绍没有写骰面）。
- 原型里「喊了比上一个更小的数字」要被别人指出才受罚；这里由程序直接不允许。
- 每轮得分：查到的两份规则介绍说法不一（一份是结束者 3 分、其他活着的 1 分，另一份是活着的都 1 分）。这里采用前者。

**待确认的默认值**：骰子点数范围；每轮得分口径；赢家分值。
