# 别拿第六张（rowcards）— 规则规格

首发游戏之一，方向：纯规则卡牌（机制参考：同时出牌、按大小接入牌列、避免吃罚分的玩法）。名称、牌面范围与罚分表为本项目自定。实现：`packages/games/src/rowcards/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 2–8 人，个人竞争 |
| 内容 | 不使用题库，不调用模型；牌局由程序生成并校验 |
| 设置 | `hands` 局数（默认 1）；`chooseSeconds` 出牌时限（默认 45，0 = 不限时） |
| 牌 | 数字 1–100，每张带罚分：11 的倍数 5 分，10 的倍数 3 分，5 的倍数 2 分，其余 1 分 |
| 发牌 | 每人 10 张，桌上 4 行各 1 张起始牌；洗牌结果随状态持久化，恢复时不重发 |
| 秘密信息 | 各人手牌只有本人可见；本墩暗出的牌在所有人出完前不公开（只公开谁已出牌） |
| 出牌 | 每墩所有人同时暗出一张；出完后立即按从小到大依次放置，不设停留页 |
| 放置规则 | 放到「末尾牌比它小且最接近」的那一行；若该行已有 5 张，收走这 5 张并以自己的牌重开该行；若比所有行末尾都小，**自动**收走罚分最少的一行（并列取靠上的一行） |
| 一局结束 | 10 墩打完；罚分最少者 +3 聚会积分（并列都得）。罚分只在局内比较 |
| 超时 | 未出牌的玩家自动打出手中最小的牌；房主也可手动触发 |
| 跳过 | 不支持投票跳过（PRD：跳题不泛化为跳过卡牌动作）；房主可结束本游戏 |
| 中途加入 | 从下一局开始发牌 |
| 断线 / 重启恢复 / 过期操作 | 同其它游戏：身份与手牌保留；重启后暂停待房主继续；动作携带 `step` |

**待确认的默认值**：牌太小时「自动收走罚分最少的一行」（而不是让玩家自己选行）；牌面范围与罚分表；多局是否累计罚分到某个上限才结束。
