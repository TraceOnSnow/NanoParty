# 百分比竞猜（percent）— 规则规格

方向：房间内比例竞猜（机制参考：猜「有百分之多少的人……」、其他人押更高或更低的玩法）。题目、名称、规则细节为本项目自定。实现：`packages/games/src/percent/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–8 人 |
| 内容 | 题库类型 `yesno-prompt`：`{"text": 一个关于「你」的是非题}`。不调用模型 |
| 数据来源 | **所有数字都来自本房间玩家这一轮的真实作答**，不使用、不编造任何外部统计 |
| 设置 | `rounds` 轮数（默认 6，0 = 不限）；`answerSeconds` 作答时限（默认 30 秒）；`betSeconds` 竞猜与押注时限（默认 45 秒）；`pickSeconds` 选题时限 |
| 选题 | 每轮一名竞猜者（轮流）从候选题里选一道，可以换一批或自己出题 |
| 作答 | 所有人（包括竞猜者）秘密回答「是 / 否」 |
| 竞猜 | 竞猜者猜有几个人答「是」（界面同时显示成百分比） |
| 押注 | 其他人押实际人数比猜测「更高」或「更低」 |
| 秘密信息 | 个人回答对任何人都不公开，揭晓时只公开作答人数和答「是」的人数（全员一致时等同于公开，这是玩法本身的性质） |
| 计分 | 竞猜者：完全猜中 +3，只差 1 人 +1。其他人：押对方向 +1；竞猜者完全猜中时没人得押注分 |
| 超时 | 作答超时以已有回答继续（少于 2 人作答则本轮不计分）；竞猜或押注超时以已有提交结算 |
| 跳过 | 作答阶段可投票跳过这道题 |
| 中途加入 | 下一轮开始参与 |

**待确认的默认值**：人数少时比例很粗，是否改成「差距越小分越高」的连续计分。
