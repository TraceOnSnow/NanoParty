# 别翻重（flipout）— 规则规格

方向：翻牌、别翻到重复的数字（机制参考：「集齐七张不同数字」的翻牌桌游及其带对抗牌的续作）。名称、文案为本项目自定。实现：`packages/games/src/flipout/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 2–8 人 |
| 内容 | 不使用题库，不调用模型 |
| 设置 | `target` 目标分（默认 200）；`turnSeconds` 每步时限（默认 0 = 不限时） |
| 牌组 | 108 张：数字 92 张（0 一张，1–13 每个数字有与数值相同的张数）；减分牌 6 张（−2、−4、−6、−8、−10、÷2 各一）；行动牌 10 张（再来一张、连翻四张、换、偷、弃各两张）。牌堆跨轮使用，翻完后把弃牌洗回 |
| 发牌 | 每轮从庄家下一位起每人翻一张；翻到减分牌或行动牌立即处理。庄家每轮顺移 |
| 回合 | 轮到的人选「再翻一张」或「停」。停下后这轮不再行动，但面前的牌仍可能被别人动 |
| 爆掉 | 翻到（或被换到、偷到）面前已有的数字，这轮 0 分。减分牌不会让人爆 |
| 七张 | 面前有 7 张数字牌，这一轮立刻结束，该玩家 +15 |
| 减分牌 | 翻到的人决定给谁：自己或任何没爆的人（包括已经停的人）。只剩自己没爆时自动留给自己 |
| 再来一张 | 翻到的人指定一位没爆的玩家：再翻一张，然后必须停 |
| 连翻四张 | 指定一位没爆的玩家连翻四张，翻重或集齐七张就停。途中翻到的减分牌和行动牌先放着，四张都翻完没爆才按顺序由这位玩家处理；爆了则作废 |
| 换 | 翻到的人选两位没爆的玩家面前各一张牌互换（数字或减分牌），可能让人爆 |
| 偷 | 翻到的人从别人面前拿一张牌到自己面前，拿到重复数字会爆 |
| 弃 | 翻到的人选任何没爆的玩家（含自己）面前一张牌弃掉 |
| 特殊数字 | 0：算作一张数字，但持有者这轮只得 0 分且不能主动停，除非集齐七张。厄运 7：到谁面前，谁面前其它牌全部弃掉，之后再来 7 仍会爆。幸运 13：持有者可以多拿一张 13 不爆，第三张才爆 |
| 算分 | 没爆的人：数字相加 → 有 ÷2 则除以 2 向下取整 → 减去减分牌 → 最低 0 分 → 集齐七张的人再 +15 |
| 结束 | 某一轮结束时有人总分达到目标分，总分最高的人赢 |
| 秘密信息 | 只有牌堆和弃牌堆的顺序与内容不公开；每个人面前的牌全部公开 |
| 计分 | 赢家 +3（并列都得） |
| 超时 | 轮到时自动停（持有 0 则自动翻）；要分配的牌留给自己；要使用的行动牌作废 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 下一轮加入 |

与原型不同的地方：

- 「换」「偷」「弃」固定由翻到的人使用，不能转交给别人使用。
- 没有实现「残酷模式」（轮分可为负、减分牌可给已爆的人、七张可改为扣别人 15 分）。
- 并列第一时都算赢家（原型规则没有给出决胜方法）。

**待确认的默认值**：目标分 200 一局偏长，是否把默认值降到 100；赢家分值。
