# 攒七张（seven）— 规则规格

方向：手牌互相加减分的摸一弃一（机制参考：「每人固定张数的手牌，牌的效果取决于手里其它牌的类别，弃牌区摆满即结束」的手牌构筑玩法）。名称、牌表、数值为本项目自定。实现：`packages/games/src/seven/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 2–6 人 |
| 内容 | 主题（`seven-theme`）：给 8 个类别起名，可选地给 56 张牌起名。主题只是名字，不影响规则。不调用模型 |
| 设置 | `turnSeconds` 每步时限（默认 0 = 不限时） |
| 牌组 | 56 张，8 个类别各 7 张；每张有基础分和 0–2 条效果 |
| 发牌 | 每人 7 张，其余为暗牌堆 |
| 回合 | 先摸一张：牌堆顶的暗牌，或公开弃牌区里的任意一张；再从手里弃一张到弃牌区 |
| 结束 | 弃牌区达到 10 张时立刻结束 |
| 效果种类 | 每有一张某类别 ±分；有某类别 +分；没有某类别 ±分；没有某类别则自己作废；让某类别全部作废；每种类别 +分；类别全不相同 +分；加上其它牌的最高基础分 |
| 作废 | 先结算作废，分两步：先判「自己作废」的牌，再由没作废的牌去作废别的类别。作废的牌 0 分、效果失效、不再算作它的类别 |
| 算分 | 没作废的牌按「基础分 + 效果」计分，相加为总分 |
| 秘密信息 | 每人的手牌只有本人可见，结束时全部公开；牌堆不公开；弃牌区公开 |
| 计分 | 结束时每人获得等于自己总分的原始分（负数按 0） |
| 超时 | 摸牌堆顶（牌堆空则拿弃牌区第一张）并把这张牌弃掉 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 不支持，下一局加入 |

主题的选择与「凑一桌」相同：取 `weight` 最高的一个，可用 `CONTENT_DIR` 加载私有主题。

**待确认的默认值**：各牌的基础分和效果分值没有经过大量对局验证；弃牌区结束张数（10）。
