# 地点疑云（spy）— 规则规格

方向：全桌知道地点、只有一人不知道的问答推理（机制参考：「一个间谍不知道地点」的聚会桌游）。名称、地点表、文案为本项目自定。实现：`packages/games/src/spy/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–8 人 |
| 内容 | 地点是写在规则模块里的固定列表（30 个常见场所），不走题库，不调用模型 |
| 设置 | `rounds` 轮数（默认 3，0 = 不限）；`talkSeconds` 每轮提问时间（默认 360 秒，0 = 不限时） |
| 开局 | 随机一个本局没用过的地点，随机一人为外人。其他人看到地点，外人只看到「你是外人」。所有人都能看到 30 个候选地点 |
| 提问 | 在语音里进行，程序不记录问答：点名问任何人一个问题，被问的人回答后接着问别人 |
| 指认 | 提问期间，每人每轮可发起一次指认（不能指自己）。发起人算一票同意，被指认的人不投票，其余人投同意或反对。同意严格过半：翻开——是外人则大家赢，不是则外人赢。没过半：回到提问 |
| 外人猜地点 | 提问期间外人可以随时从列表里猜一个地点，这一轮立刻结束：猜对外人赢，猜错大家赢 |
| 最终指认 | 时间到，或房主点「开始最终指认」：每人指一个人（不能指自己）。票数唯一最高的人如果是外人，大家赢；否则（包括平票）外人赢 |
| 秘密信息 | 地点不发给外人；谁是外人不发给任何其他人；投票和最终指认在全部投完前只公开「谁投了」。一轮结束后全部公开 |
| 计分 | 外人赢：外人 +3。大家赢：非外人每人 +1，通过指认抓到外人的发起人再 +1 |
| 超时 | 提问时间到（包括正在投票时）进入最终指认；最终指认不计时 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 下一轮加入（这一轮看不到地点） |

与原型不同的地方：没有每个地点下的「角色」；指认用过半而不是全票；计分简化。

**待确认的默认值**：提问时间；指认是否改为全票；是否把地点表改成可导入的题库。
