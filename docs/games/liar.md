# 吹牛骰子（liar）— 规则规格

方向：酒桌上的传统骰子游戏（大话骰）。实现：`packages/games/src/liar/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 2–8 人 |
| 内容 | 不使用题库，不调用模型 |
| 设置 | `rounds` 轮数（默认 8，0 = 不限）；`turnSeconds` 每步时限（默认 0 = 不限时） |
| 骰子 | 每人 5 颗，每轮重新摇，只有本人看得到 |
| 叫数 | 第一轮由第一位玩家起叫，之后由上一轮输的人起叫。叫「几个几」= 全桌至少有这么多个这个点数。起叫个数不少于人数；之后必须比上家大：个数更多，或个数相同而点数更大（2 < 3 < 4 < 5 < 6 < 1）；个数不超过全桌骰子总数 |
| 万能 1 | 1 点可以当任何点数；一旦有人叫了 1，这一轮 1 不再万能 |
| 开 | 轮到的人可以不叫而「开」上家：全桌亮骰子清点。够数——开的人输；不够——被开的人输 |
| 结束 | 打完设定的轮数，或房主在两轮之间选择「就玩到这」 |
| 秘密信息 | 别人的骰子在开之前不发给客户端 |
| 计分 | 输的轮数最少的人 +3（并列都得） |
| 超时 | 面前有人叫了就自动开，否则自动按最低起叫（人数个 2） |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 下一轮加入 |

没有实现的地方玩法：「斋」（叫数时声明 1 不万能）、「劈」和「反劈」、顺子和豹子的特殊算法、输了扣骰子的淘汰制。

**待确认的默认值**：轮数；是否需要上面这些地方玩法作为可选项。
