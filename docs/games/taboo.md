# 禁词描述（taboo）— 规则规格

方向：禁词描述（机制参考：描述目标词但不能说出指定禁词的玩法）。词卡、名称、文案为本项目自定。实现：`packages/games/src/taboo/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–8 人，不分队 |
| 内容 | 题库类型 `taboo-card`：`{"word": 目标词, "taboo": [2–5 个禁词]}`。不调用模型 |
| 设置 | `laps` 每人描述次数（默认 1）；`turnSeconds` 每回合时限（默认 75 秒，20–300） |
| 角色 | 每回合一名描述者（按加入顺序轮流）和一名裁判（描述者的下一位）。两人都能看到词卡 |
| 描述 | 描述者在语音里描述，不能说目标词、禁词或它们的一部分，不能用谐音和外语 |
| 猜词 | 其他人在网页上输入猜测，与目标词一致（忽略空格、标点、大小写）即猜中，自动换下一张。裁判不能猜 |
| 跳过 / 犯规 | 描述者可以跳过当前词；裁判听到禁词按「犯规」，这张作废。都直接换下一张，不扣分 |
| 回合结束 | 时限到；或词卡用完 |
| 秘密信息 | 当前词卡只发给描述者和裁判；回合中已结束的词对所有人公开 |
| 计分 | 每猜中一个词：猜中的人 +1，描述者 +1 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 下一回合起可以猜，并排到描述顺序末尾（总回合数不变） |
| 无法约束的部分 | 是否说了禁词由裁判判断，系统听不到语音 |

**待确认的默认值**：是否改成两队对抗；犯规是否扣分。
