# 不撞词（oneclue）— 规则规格

首发游戏之一，方向：合作猜词（机制参考：各给一个线索、重复线索失效的合作玩法）。名称、内容与分值为本项目自定，不使用任何商业作品的名称或素材。实现：`packages/games/src/oneclue/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–8 人，合作 |
| 内容 | 题库类型 `guess-word`：一个目标词 |
| 设置 | `rounds`（默认 6）；`clueSeconds`（默认 60）；`guessSeconds`（默认 60） |
| 猜词者 | 每轮一名，担任次数最少者优先 |
| 选题 | 每轮正式开始前，由猜词者以外的一名玩家（轮流担任）从 3 个候选词里选一个；可以不限次数地换一批，或自己出一个。猜词者看不到候选，网络数据里也没有。换一批不消耗题库，只有确认的题才计为已用；选题阶段不算回合开始，不能投票跳过。AI 交来的候选题会替换当前候选，若本轮已开始则留到下一轮。选题时限 `pickSeconds`（默认 60 秒），超时用第一道候选。出题人也照常参与本轮 |
| 秘密信息 | 目标词对猜词者保密直到揭晓；线索在全部提交前互不可见；撞词作废的线索内容在揭晓前不发给猜词者 |
| 线索 | 其他人各写一个词（≤10 字），不能包含目标词或被目标词包含 |
| 撞词判定 | 去除空白和标点、忽略大小写后完全相同的线索全部作废 |
| 猜词 | 猜词者一次机会，可放弃；规范化后与目标词相同即猜中 |
| 人工裁定 | 没猜中但意思相同时，房主可「判为猜中」（只能改判一次，不会重复加分） |
| 计分（团队） | 猜中：本轮全员 +1 |
| 超时 | 线索超时：用已有线索进入猜词；猜词超时：视为放弃 |
| 跳过 | 揭晓前可投票跳过，不计分 |
| 中途加入 | 从下一轮开始参与；等待期间看不到秘密信息 |
| 断线 | 身份与已提交内容保留；每个阶段都有超时或房主推进入口，不会被离线玩家卡住 |
| 重启恢复 | 游戏段暂停，房主继续后当前阶段计时重新开始；已发的秘密和已提交内容不变 |
| 过期操作 | 每个动作携带阶段计数 `step`，阶段一变旧动作即失效 |

**待确认的默认值**：近义线索（如「夜晚」「晚上」）是否也算撞词（目前不算，可由大家口头约定）。
