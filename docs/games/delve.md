# 探洞寻宝（delve）— 规则规格

方向：同时暗选「继续还是离开」的贪心游戏（机制参考：「一起探险、同种危险出现两次就全丢」的寻宝桌游）。名称、危险名、文案为本项目自定。实现：`packages/games/src/delve/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–8 人 |
| 内容 | 不使用题库，不调用模型 |
| 设置 | `rounds` 探洞次数（默认 5）；`chooseSeconds` 每次决定限时（默认 0 = 不限时） |
| 牌 | 宝石牌 15 张（1、2、3、4、5、5、7、7、9、11、11、13、14、15、17）；危险牌 5 种各 3 张；每趟洗入 1 张遗物牌 |
| 一趟 | 所有人进洞，翻第一张牌。之后重复：洞里的人同时暗选「继续」或「回营地」→ 公开结果 → 还有人在洞里就翻下一张 |
| 宝石牌 | 洞里的人平分，拿在手里；分不完的留在这张牌上 |
| 危险牌 | 某种危险第一次出现无事；同一趟第二次出现：洞里所有人手里的宝石清零，这一趟结束，并把这张危险牌永久移出（以后这种危险只剩两张） |
| 回营地 | 这一步选择回营地的人平分路上各张牌剩下的宝石（分不完的继续留着），连同手里的一起存进帐篷，这一趟不再参与 |
| 遗物 | 留在路上，只有某一步**恰好一个人**回营地时由他带走。按被带走的先后，前三件每件值 5，之后每件值 10。没被带走的遗物随这一趟作废 |
| 结束 | 探完设定的次数，帐篷里宝石最多的人赢 |
| 秘密信息 | 每一步的选择在所有人选完前不公开（只公开谁已经选了）；帐篷里的数量只有本人可见，游戏结束才公开；牌堆顺序不公开 |
| 计分 | 赢家 +3（并列都得） |
| 超时 | 没选的人视为回营地 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 下一趟加入 |

与原型不同的地方：每趟固定洗入一张遗物牌（原型是每趟多加一张，之前没被带走的也留在牌堆里）。

**待确认的默认值**：赢家分值；遗物规则是否改回逐趟累加。
