# 密码传递（codebreak）— 规则规格

方向：两队密码传递与拦截（机制参考：用提示向队友传递数字密码、同时防止对手破译的玩法）。词库、名称、文案为本项目自定。实现：`packages/games/src/codebreak/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 4–8 人，按加入顺序交替分成红蓝两队 |
| 内容 | 使用内置词表，不使用题库，不调用模型 |
| 设置 | `clueSeconds` 写提示时限、`guessSeconds` 解读时限（默认都为 0 = 不限时） |
| 关键词 | 每队 4 个，编号 1–4，整局只有本队可见 |
| 每轮 | 两队各一名传令员（队内轮换）拿到一组三位密码（1–4 中不重复的三个数字，有顺序），按顺序为每一位写一条提示。提示不能包含本队关键词 |
| 公开 | 两队都提交后，提示同时公开 |
| 解读 | 传令员以外的队员提交对本队密码的解读；第 2 轮起，每队任一队员提交对对方密码的破译。每队每项只收第一份提交 |
| 结算 | 本队解错（或没提交）→ 本队 1 次「失误」；破译对方成功 → 本队 1 次「拦截」。之后公开双方密码和各自的提交，累计成历史表 |
| 结束 | 任一队拦截达到 2 次或失误达到 2 次，或打满 8 轮。按「拦截 − 失误」多者胜，相同为平局 |
| 秘密信息 | 关键词只发给本队；密码只发给传令员；提示在双方都提交前只有作者可见；本队提交的解读在揭晓前只有本队可见 |
| 计分 | 获胜队伍每人 +3；平局不得分 |
| 超时 | 写提示超时 → 直接公开已有提示；解读超时 → 以已有提交结算 |
| 跳过 | 不支持投票跳过；房主可推进阶段或结束游戏 |
| 中途加入 | 不支持，下一次开始游戏时加入 |

**待确认的默认值**：结束条件用的是净值比较而不是「2 次拦截直接胜 / 2 次失误直接负」；是否加入最终猜关键词的加赛。
