# 四叶联想（clover）— 规则规格

方向：合作联想还原（机制参考：为相邻词对写提示、再由队友凭提示还原卡片位置的合作玩法）。词库、名称、文案为本项目自定。实现：`packages/games/src/clover/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–6 人，全员合作 |
| 内容 | 使用内置词表，不使用题库，不调用模型 |
| 设置 | `writeSeconds` 写提示时限（默认 0 = 不限时） |
| 发牌 | 每人 4 张卡围成一圈，每张卡两个词；另有 1 张干扰卡（写提示时看不到）。相邻两张卡挨着的两个词组成一对，共 4 对 |
| 写提示 | 每人同时为自己的 4 对各写一条提示（最多 12 字，不能包含自己卡上的词） |
| 还原 | 依次处理每个人的四叶：4 张卡 + 干扰卡打乱，方向也可能调转。作者以外的任何人都可以把卡放到 4 个位置、调转方向、拿回；大家共用同一份摆法，任何一人可以提交 |
| 判定 | 第一次提交全对 → 6 分。否则放对的锁定、放错的退回，再提交一次，每放对一张 1 分 |
| 秘密信息 | 写提示阶段各人的卡只有本人可见；还原阶段正确摆法对所有人（包括提示）保密，结算后公开 |
| 计分 | 团队：每份四叶的得分，所有人各得同样的分数 |
| 超时 | 写提示超时：没提交的人的四叶不参与还原 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 不支持，下一次开始游戏时加入 |
| 无法约束的部分 | 作者在语音里是否给了额外提示 |

**待确认的默认值**：提示是否限制为「一个词」（目前只限长度）；卡片是否改成四个词、可旋转。
