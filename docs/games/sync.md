# 心照不宣（sync）— 规则规格

方向：没有回合的合作出牌（机制参考：「不交流，全队把 1–100 的牌从小到大打完」的合作卡牌）。名称、文案为本项目自定。实现：`packages/games/src/sync/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 2–8 人 |
| 内容 | 不使用题库，不调用模型 |
| 设置 | `levels` 关数（默认 0 = 按人数：2 人 12 关，3 人 10 关，4 人 8 关，5 人以上 6 关；并且不超过「100 ÷ 人数」） |
| 牌 | 1–100 各一张，每关重新洗牌。第 N 关每人 N 张 |
| 命和星 | 命数 = 人数（最多 5）；开局 1 颗星（最多 3）。通过第 2、5、8 关各 +1 星，通过第 3、6、9 关各 +1 命 |
| 出牌 | 没有回合。任何还有牌的人随时可以出自己**最小**的一张 |
| 失误 | 出牌时如果任何人手里还有比它小的牌：全队 −1 命，所有更小的牌亮出并弃掉，游戏继续 |
| 星 | 任何有牌的人可以提议用星；所有还有牌的人都同意时，消耗一颗星，每人亮出并弃掉自己最小的一张 |
| 过关 | 所有人手牌打完。房主点进入下一关 |
| 结束 | 命数归零（失败），或通过最后一关（通关） |
| 秘密信息 | 每人只收到自己的手牌和别人的张数；失败或通关后才公开剩余手牌。「不许透露自己的牌」靠自觉，语音无法由程序约束 |
| 计分 | 通关：每人 +3。未通关但已通过的关数不少于一半：每人 +1 |
| 操作绑定 | 这个游戏没有回合，出牌和用星绑定的是「第几次发牌」和具体的牌，而不是步数：两个人几乎同时出牌都会生效，由服务端按到达顺序判定 |
| 超时 | 不计时 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 下一关加入 |

**待确认的默认值**：5 人以上的关数和命数是自定的（原型只到 4 人）；合作游戏的给分口径。
