# 暗号网格（wordgrid）— 规则规格

方向：两队词语网格（机制参考：队长用「一个词 + 数字」提示队友找出己方词语的玩法）。词库、名称、文案为本项目自定。实现：`packages/games/src/wordgrid/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 4–8 人，按加入顺序交替分成红蓝两队 |
| 内容 | 使用内置词表（`packages/games/src/words.ts`，200 个日常名词），不使用题库，不调用模型 |
| 设置 | `games` 局数（默认 1）；`turnSeconds` 每步时限（默认 0 = 不限时） |
| 布局 | 25 个词：先手队 9、后手队 8、路人 7、陷阱 1。先手随机 |
| 队长 | 每队一名，每局在队内轮换；只有两位队长看得到归属 |
| 提示 | 轮到的队长给「一个词 + 数字 0–9」。提示词不能包含桌上未翻开的词，也不能被它们包含 |
| 猜词 | 队长以外的队员逐个点词，最多「数字 + 1」个，至少点 1 个后可以停手。点中己方词继续；点中路人或对方词，回合结束；点中陷阱，立即判负 |
| 获胜 | 一方的词全部翻开（不论是谁翻的）即获胜；或对方踩中陷阱 |
| 秘密信息 | 未翻开词的归属只发给队长；一局结束后对所有人公开 |
| 计分 | 获胜队伍每人 +3 |
| 超时 | 设了时限时，超时直接换对方回合 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 下一局加入人少的一队 |
| 无法约束的部分 | 队长在语音里的额外暗示、提示词是否「合规」（谐音、外语等）由玩家自行约定，系统只做包含关系检查 |

**待确认的默认值**：是否允许玩家自选队伍和队长；词表是否接入题库。
