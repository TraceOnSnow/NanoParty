# 撞答案（echo）— 规则规格

方向：同题各写六个答案，看谁和谁撞上（机制参考：「写答案、亮答案、押撞出几组」的默契聚会桌游）。名称、文案为本项目自定。实现：`packages/games/src/echo/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–8 人 |
| 内容 | 题目用类别题库（`category`，与逛三园共用）；出题人可以自己写一个类别。不调用模型 |
| 设置 | `rounds` 轮数（默认 3）；`writeSeconds` 写答案限时、`turnSeconds` 每步时限（默认 0 = 不限时）；`pickSeconds` 选题限时 |
| 钱 | 每人开局 150。奖池开局 30。每轮另有「本轮奖金」：第 1 轮 30，之后每轮多 20 |
| 选题 | 每轮轮换出题人，用通用选题面板选一个类别 |
| 写答案 | 所有人（含出题人）各写 6 个互不相同的答案，最长 20 字，互相看不到。都交了就开始；房主也可以在至少两人交了之后不等其他人，没交的人这一轮不参加 |
| 行动 | 从出题人的下家开始轮流，每回合二选一：亮答案或押注 |
| 亮答案 | 亮出自己一个还盖着的答案。其他人手里忽略空格、标点、大小写后完全相同的答案自动亮出，算撞上 |
| 意思相同 | 写法不同但意思一样的答案，持有者可以在下一个人行动前点「也算」亮出来认领（每人每次最多一个）。房主可以否决认领（答案保持亮出但不算），也可以判定亮出的答案不符合题目 |
| 结算一次亮答案 | 在下一个人行动时结算：撞上——亮的人拿走奖池全部，奖池补回 30，撞出组数 +1；没撞上——亮的人交 10 到奖池；不符合题目——交 20 |
| 押注 | 交 10 到奖池，押这一轮结束时一共撞出几组（0–12）。每个数字最多 2 注，每人每轮最多 4 注。押注公开 |
| 一轮结束 | 有人 6 个答案全部亮出后进入「最后认领」，房主或刚行动的人点结算。押中最终组数的人平分奖池加本轮奖金（按 10 取整，零头给最先押中的人），奖池重置为 30；没人押中，奖池加奖金滚到下一轮 |
| 结束 | 打完设定的轮数，钱最多的人赢 |
| 秘密信息 | 没亮出的答案只发给写的人；别人只看到还盖着几个。一轮结束后全部公开 |
| 计分 | 赢家 +3（并列都得） |
| 超时 | 选题取第一个候选；写答案到时就用已交的人开始；轮到时亮出第一个盖着的答案；最后认领到时自动结算 |
| 跳过 | 写答案和行动阶段可以投票跳过本题，这一轮不结算 |
| 中途加入 | 下一轮加入 |

与原型不同或自行确定的地方：

- 每轮奖金数额和押注数字范围：查到的规则介绍没有给出（原型印在图板上），这里自定为 30 起每轮 +20、0–12。
- 一次亮答案的输赢推迟到下一个人行动时才结算，给「意思相同」的认领留出时间。
- 没有在一轮结束时逐张检查剩余答案是否符合题目。
- 最少 3 人（原型标 2–8 人，两人时几乎没有可押的悬念）。

**待确认的默认值**：奖金数额；是否需要 AI 辅助判断「意思相同」；赢家分值。
