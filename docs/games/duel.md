# 暗牌对决（duel）— 规则规格

方向：单张手牌淘汰（机制参考：「摸一张、打一张、用效果淘汰对手」的微型卡牌玩法）。牌名、效果文字为本项目自定。实现：`packages/games/src/duel/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 2–6 人 |
| 内容 | 不使用题库，不调用模型 |
| 设置 | `tokens` 获胜所需轮数（默认 3）；`turnSeconds` 每步时限（默认 0 = 不限时） |
| 牌组 | 16 张：1 侦察 ×5、2 窥探 ×2、3 比拼 ×2、4 护盾 ×2、5 弃牌令 ×2、6 交换 ×1、7 顾问 ×1、8 王牌 ×1。每轮暗中移除 1 张 |
| 回合 | 每人手里 1 张。轮到你时摸 1 张，再从 2 张里打出 1 张并执行效果 |
| 效果 | 1：指定一人猜 2–8 的点数，猜中则对方出局；2：偷看一人手牌；3：与一人比点数，小的出局；4：到你下回合前别人的牌对你无效；5：让一人（可以是自己）弃牌重摸，弃掉 8 则出局；6：与一人换牌；7：无效果，但手里同时有 5 或 6 时必须打出；8：打出或被弃掉即出局 |
| 目标 | 不能指定已出局或有护盾的人；没有合法目标时牌照打、效果落空 |
| 一轮结束 | 只剩一人，或牌堆摸完时手牌点数最大者获胜 |
| 秘密信息 | 手牌只有本人可见；窥探、比拼的结果只告诉当事人；被移除的牌不公开 |
| 计分 | 每赢一轮 +1；先赢够轮数的人再 +2 |
| 超时 | 自动打出较小的那张（7 被强制时打 7），指向第一个合法目标，侦察猜 2 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 下一轮加入 |

**待确认的默认值**：牌堆摸完且点数并列时的处理；2 人局是否额外移除牌。
