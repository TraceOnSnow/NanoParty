# 估数下注（wager）— 规则规格

首发游戏之一，方向：估数 + 下注（机制参考：先估数再押谁更接近的玩法）。名称、内容与分值为本项目自定，不使用任何商业作品的名称或素材。实现：`packages/games/src/wager/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–8 人，个人竞争 |
| 内容 | 题库类型 `numeric-fact`（与「估数字」共用）：题干、单位、数字答案、可选口径 |
| 设置 | `rounds`（默认 5）；`answerSeconds`（默认 60）；`betSeconds`（默认 45） |
| 选题 | 每轮正式开始前，由轮流担任的出题人从 3 道候选里选一道，只看得到题干、看不到答案；可以换一批，不能自己出题（自拟需要写答案）。题库耗尽时游戏结束。换一批不消耗题库，只有确认的题才计为已用；选题阶段不算回合开始，不能投票跳过。AI 交来的候选题会替换当前候选，若本轮已开始则留到下一轮。选题时限 `pickSeconds`（默认 60 秒），超时用第一道候选。出题人也照常参与本轮 |
| 秘密信息 | 答案在揭晓前不公开；各人的估计在全部提交前不公开；各人的下注在揭晓前不公开 |
| 估数 | 每人提交一个数字，不可修改 |
| 下注 | 公开所有估计（从小到大，带名字），每人押一位玩家的估计最接近（可押自己）。不同估计少于两个时跳过下注 |
| 计分 | 最接近者 +2（并列都得），完全猜中再 +1；押中最接近者 +1 |
| 超时 | 估数超时：用已有估计进入下注；下注超时：按已下注结算 |
| 跳过 | 揭晓前可投票跳过，不计分 |
| 中途加入 | 从下一轮开始参与；等待期间看不到秘密信息 |
| 断线 | 身份与已提交内容保留；每个阶段都有超时或房主推进入口，不会被离线玩家卡住 |
| 重启恢复 | 游戏段暂停，房主继续后当前阶段计时重新开始；已发的秘密和已提交内容不变 |
| 过期操作 | 每个动作携带阶段计数 `step`，阶段一变旧动作即失效 |

**待确认的默认值**：是否引入筹码与赔率（目前是固定 1 分的简单下注）；是否采用「不超过答案的最接近者」规则。
