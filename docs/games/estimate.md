# 估数字（estimate）— 规则规格

> 用于验证架构的示例玩法，不代表首发游戏名单。实现：`packages/games/src/estimate/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 2–8 人，个人竞争，不组队 |
| 内容 | 题库类型 `numeric-fact`：题干、单位、数字答案、可选口径说明。无 AI 时使用内置题库 |
| 设置 | `rounds` 轮数（默认 5，0 = 不限，由房主结束）；`answerSeconds` 答题时限（默认 60，0 = 不限时） |
| 秘密信息 | 正确答案、每位玩家提交的数值，在揭晓前只存在于服务端；谁已提交是公开的 |
| 答题阶段 | 参与者各提交一个数字，提交后不可修改 |
| 揭晓条件 | 全部参与者已提交，或超时，或房主「提前揭晓」 |
| 计分 | 最接近者 +2（并列都得），完全猜中再 +1；未提交不得分 |
| 揭晓后 | 停留在结果页，由房主点击「下一轮」；不自动切走 |
| 跳题 | 仅答题阶段、房主直接跳过；不计分，进入下一题（投票跳题待平台实现） |
| 结束 | 达到轮数，或题池耗尽（`endedBecause` 区分），回到大厅并保留积分 |
| 中途加入 | 从下一轮开始参与；本轮只能围观，看不到秘密 |
| 断线 | 身份与已提交内容保留；断线玩家不会无限卡住流程（超时或房主提前揭晓） |
| 重启恢复 | 游戏段暂停，房主继续后答题计时重新开始；题目与已提交内容不变 |
| 过期操作 | 每个动作携带回合号，回合不匹配即拒绝 |
