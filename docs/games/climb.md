# 贪心登顶（climb）— 规则规格

方向：掷骰子、见好就收（机制参考：「四颗骰子分成两对，在十一列上爬，先占三列者胜」的经典骰子桌游）。名称、文案为本项目自定。实现：`packages/games/src/climb/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 2–6 人（原型为 2–4 人；人多时每人回合间隔变长，规则不变） |
| 内容 | 不使用题库，不调用模型 |
| 设置 | `games` 局数（默认 1）；`turnSeconds` 每步时限（默认 0 = 不限时） |
| 棋盘 | 2–12 共十一列。到顶的步数：2 和 12 是 3 步，每靠近 7 一列多 2 步，7 是 13 步 |
| 回合 | 掷四颗骰子，分成两对，两对的和就是要前进的两列。每回合最多同时在 3 列上放临时攀登者。两个和都能走时必须都走；只能走其中一个时由玩家选；同一个和出现两次就在该列走两步 |
| 继续或停下 | 每次前进后二选一：停下，把临时攀登者的位置存为自己的进度；或再掷一次 |
| 作废 | 掷出的骰子任何分法都走不了（列已被占、已到顶、或已有 3 个攀登者且都对不上），这回合的临时进度全部作废，轮到下一个人 |
| 占列 | 停下时到顶的列归该玩家，其他人之后不能再走这一列；别人在该列的进度作废 |
| 结束 | 有人占到 3 列 |
| 秘密信息 | 没有。所有人看到的桌面相同 |
| 计分 | 每局赢家 +3 |
| 超时 | 需要分骰子时走第一种走法；需要决定时，有临时进度就停下，没有就掷一次 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 下一局加入 |

**待确认的默认值**：赢家分值；是否给第二名分；5–6 人时是否需要调整获胜列数。
