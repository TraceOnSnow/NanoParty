# 真假难辨（bluff）— 规则规格

首发游戏之一，方向：编假答案（机制参考：把假答案混入真答案互相欺骗的玩法）。名称、内容与分值为本项目自定，不使用任何商业作品的名称或素材。实现：`packages/games/src/bluff/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–8 人，个人竞争 |
| 内容 | 题库类型 `fact-blank`：带空缺的事实题 + 真答案 + 可选口径说明。内置题标记为「未核实」 |
| 设置 | `rounds`（默认 5）；`writeSeconds`（默认 90）；`pickSeconds`（默认 45） |
| 选题 | 每轮正式开始前，由轮流担任的出题人从 3 道候选里选一道，只看得到题干、看不到答案；可以换一批，不能自己出题（自拟需要写答案）。题库耗尽时游戏结束。换一批不消耗题库，只有确认的题才计为已用；选题阶段不算回合开始，不能投票跳过。AI 交来的候选题会替换当前候选，若本轮已开始则留到下一轮。选题时限 `pickSeconds`（默认 60 秒），超时用第一道候选。出题人也照常参与本轮 |
| 秘密信息 | 真答案、各人的假答案及作者、各人的选择，揭晓前都不公开 |
| 编答案 | 每人写一个假答案（≤30 字）；规范化后与真答案相同会被要求重写 |
| 选择 | 相同的假答案合并为一项；所有选项乱序匿名展示；不能选自己写的 |
| 计分 | 选中真答案 +2；自己的假答案每骗到 1 人 +1（合并项的每位作者各得） |
| 超时 | 编答案超时：用已有假答案进入选择；选择超时：按已选结算 |
| 争议 | 答案有误可用「这题有问题」反馈；已结算题的作废/改分流程待平台实现 |
| 跳过 | 揭晓前可投票跳过，不计分 |
| 中途加入 | 从下一轮开始参与；等待期间看不到秘密信息 |
| 断线 | 身份与已提交内容保留；每个阶段都有超时或房主推进入口，不会被离线玩家卡住 |
| 重启恢复 | 游戏段暂停，房主继续后当前阶段计时重新开始；已发的秘密和已提交内容不变 |
| 过期操作 | 每个动作携带阶段计数 `step`，阶段一变旧动作即失效 |

**待确认的默认值**：分值；碰巧写中真答案时是「要求重写」还是「直接算对」。
