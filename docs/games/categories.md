# 逛三园（categories）— 规则规格

首发游戏之一，方向：类别轮答。名称、内容与分值为本项目自定，不使用任何商业作品的名称或素材。实现：`packages/games/src/categories/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 2–8 人，个人竞争 |
| 内容 | 题库类型 `category`：类别名 + 可选提示 |
| 设置 | `rounds`（默认 3，0 = 不限）；`turnSeconds` 每人每次限时（默认 20，0 = 不限时） |
| 秘密信息 | 无，全部公开 |
| 流程 | 按加入顺序轮流，轮到的人输入一个词（≤20 字）；起始座位每轮轮换 |
| 重复判定 | 去除空白和标点、忽略大小写后与已有有效词完全相同即拒绝；被拒不结束回合，计时不停 |
| 类别是否成立 | 不由程序或模型判断。大家口头把关；房主可「判最新的词无效」，该词作者出局 |
| 出局 | 超时、认输、被判无效 |
| 计分 | 剩最后一人时本轮结束，TA +2 |
| 跳过 | 进行中可投票跳过该类别，不计分 |
| 中途加入 | 从下一轮开始参与；等待期间看不到秘密信息 |
| 断线 | 身份与已提交内容保留；每个阶段都有超时或房主推进入口，不会被离线玩家卡住 |
| 重启恢复 | 游戏段暂停，房主继续后当前阶段计时重新开始；已发的秘密和已提交内容不变 |
| 过期操作 | 每个动作携带阶段计数 `step`，阶段一变旧动作即失效 |

**待确认的默认值**：同义词/别名是否算重复（目前只判完全相同）；是否允许非房主发起质疑投票。
