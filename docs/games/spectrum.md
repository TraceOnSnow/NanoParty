# 猜刻度（spectrum）— 规则规格

首发游戏之一，对应 PRD 候选目录的「光谱与程度」方向（机制参考：电波同步类玩法）。名称、刻度内容与分值均为本项目自定，不使用任何商业作品的名称、卡牌或素材。实现：`packages/games/src/spectrum/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 2–8 人，个人计分，不组队 |
| 内容 | 题库类型 `spectrum`：一对相反的两端概念（如 冷 ↔ 热）。无 AI 时使用内置题库 |
| 设置 | `rounds` 轮数（默认 6，0 = 不限）；`pickSeconds` 选题时限（默认 90）；`clueSeconds` 写提示时限（默认 120）；`guessSeconds` 猜测时限（默认 90）；0 = 不限时 |
| 提示者 | 每轮一名，按「担任次数最少者优先、同次数按加入顺序」轮换 |
| 秘密信息 | 目标位置（0–100 上的 5–95）只有提示者可见；各人的猜测在揭晓前互不可见；谁已提交是公开的 |
| 选题阶段 | 每轮正式开始前，提示者从 3 张候选刻度里选一张；可以不限次数地「换一批」（只是换着看，不消耗题库、不算跳题），或自己写两端（≤12 字，保存进题库，来源记为玩家自拟）。AI 交来的候选题会替换当前候选；若本轮已开始，则留到下一轮选题。选题超时则用第一张候选。其他人可以看到候选。 |
| 提示阶段 | 提示者写一句不超过 30 字的提示，不能包含数字 |
| 猜测阶段 | 其他参与者各自拖动滑块提交一个位置，提交后不可修改 |
| 揭晓条件 | 全部猜测者已提交，或超时，或房主「提前揭晓」 |
| 计分 | 偏差 ≤5 得 4 分，≤12 得 3 分，≤22 得 2 分，其余 0 分；提示者得猜测者得分的平均值（四舍五入） |
| 揭晓后 | 停留在结果页，由房主点击「下一轮」 |
| 超时 | 提示超时：本轮作废不计分，换下一位提示者；猜测超时：按已收到的猜测结算 |
| 跳过 | 选题阶段换题不算跳过；正式开始后（提示或猜测阶段），房主可直接跳过或大家投票跳过本轮，不计分（投票跳题待平台实现） |
| 结束 | 达到轮数，或题池耗尽，回到大厅并保留积分 |
| 中途加入 | 从下一轮开始参与 |
| 断线 | 身份与已提交内容保留；提示者离开时可由超时或房主跳过，不会卡住 |
| 重启恢复 | 游戏段暂停，房主继续后当前阶段计时重新开始；刻度、目标、提示和已提交猜测不变 |
| 过期操作 | 每个动作携带回合号，不匹配即拒绝 |

**待你确认的默认值**：分值档位、时限、「提示不能含数字」这一限制，以及是否需要团队合作计分的变体。
