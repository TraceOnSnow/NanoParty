# 合作吃墩（crew）— 规则规格

方向：合作吃墩（机制参考：团队协作完成赢墩任务的卡牌玩法）。牌组、任务和名称为本项目自定。实现：`packages/games/src/crew/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–5 人，全员合作 |
| 内容 | 不使用题库，不调用模型 |
| 设置 | `missions` 任务次数（默认 3）；`tasks` 首次任务牌数（默认 2，每成功一次 +1）；`turnSeconds` 出牌时限（默认 0 = 不限时） |
| 牌组 | 红蓝绿黄 1–9 各一张 + 王牌 1–4，共 40 张，全部发完（3 人时有人多一张） |
| 队长 | 持有王牌 4 的人 |
| 任务 | 随机翻出若干张彩色任务牌，从队长起轮流认领 |
| 出牌 | 队长先领；必须跟领出的花色，没有才可以出别的。有王牌时最大的王牌赢，否则领出花色中最大的赢；赢家领下一墩 |
| 任务判定 | 任务牌所在的墩被认领人赢下 → 完成；被别人赢下 → 整个任务立即失败 |
| 沟通 | 每人每次任务一次，只能在两墩之间：公开一张彩色手牌，系统标明它是该颜色中「最大 / 最小 / 唯一」（不满足就不能公开）。其余手牌信息请不要在语音里透露（系统无法监听） |
| 秘密信息 | 手牌只有本人可见；公开的牌、已出的牌和任务对所有人可见 |
| 计分 | 团队：全部任务完成，所有人 +3；失败不得分 |
| 超时 | 设了时限时，未行动的玩家自动认领第一个空任务 / 出第一张合法牌 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 下一次任务开始时发牌（人数需在 3–5 之间） |

**待确认的默认值**：任务难度递增方式；是否加入「顺序任务」等任务标记；沟通规则。
