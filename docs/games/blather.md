# 词块描述（blather）— 规则规格

方向：受限词汇描述（机制参考：只能用固定句式和有限词汇描述答案的玩法）。句式、词块、名称为本项目自定。实现：`packages/games/src/blather/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–8 人 |
| 内容 | 目标词来自题库类型 `guess-word`（与「不撞词」「问出秘密词」共用）；句式和词块内置在规则模块里。不调用模型 |
| 设置 | `rounds` 轮数（默认 6，0 = 不限）；`roundSeconds` 每轮时限（默认 150 秒）；`pickSeconds` 选词时限 |
| 选词 | 每轮一名描述者（轮流），从候选词里选一个，可以换一批或自己写；候选只有描述者看得到 |
| 描述 | 描述者只能从 6 个句式（「它是一种____」「它____」「它常出现在____」「人们用它来____」「它让人感到____」「它的颜色通常是____」）里选词块拼句子，每句公开显示，最多 20 句，不能重复 |
| 猜词 | 其他人随时输入猜测；与目标词一致即猜中，本轮结束。描述者可以给猜错的答案标「接近」或「不对」 |
| 秘密信息 | 目标词只发给描述者，揭晓后公开；词块面板只发给描述者 |
| 计分 | 猜中的人 +2，描述者 +1；没人猜中都不得分 |
| 超时 | 选词超时用第一个候选；描述超时直接揭晓 |
| 跳过 | 描述阶段可投票跳过本轮（不计分） |
| 中途加入 | 下一轮开始参与 |
| 无法约束的部分 | 描述者在语音里的额外提示，系统听不到 |

**待确认的默认值**：句式与词块的数量和内容；是否按用掉的句子数递减得分。
