# 脑洞问答（quip）— 规则规格

首发游戏之一，方向：开放回答 + 投票（机制参考：给搞笑问题写答案再互相投票的玩法）。名称、内容与分值为本项目自定，不使用任何商业作品的名称或素材。实现：`packages/games/src/quip/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–8 人，个人竞争 |
| 内容 | 题库类型 `quip-prompt`：一个开放问题 |
| 设置 | `rounds`（默认 5）；`writeSeconds`（默认 90）；`voteSeconds`（默认 60） |
| 秘密信息 | 回答在作答阶段互不可见；投票阶段回答匿名、乱序，作者与票数在揭晓前不公开 |
| 作答 | 所有人对同一题各写一个回答（≤60 字） |
| 投票 | 每人投一票，不能投自己的回答；回答少于两个时跳过投票且不计分 |
| 计分 | 每得 1 票 +1；得票最多的回答再 +1（并列都加） |
| 超时 | 作答超时：用已有回答进入投票；投票超时：按已投结算 |
| 跳过 | 揭晓前可投票跳过，不计分 |
| 中途加入 | 从下一轮开始参与；等待期间看不到秘密信息 |
| 断线 | 身份与已提交内容保留；每个阶段都有超时或房主推进入口，不会被离线玩家卡住 |
| 重启恢复 | 游戏段暂停，房主继续后当前阶段计时重新开始；已发的秘密和已提交内容不变 |
| 过期操作 | 每个动作携带阶段计数 `step`，阶段一变旧动作即失效 |

**待确认的默认值**：是否改为两两对决的形式；分值。
