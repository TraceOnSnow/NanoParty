# 凑一桌（platter）— 规则规格

方向：双面牌的市场选牌与规则计分（机制参考：「牌的一面是材料、另一面是计分规则，轮流从市场拿一张规则或两张材料」的选牌玩法）。名称、牌表、数值为本项目自定。实现：`packages/games/src/platter/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 2–6 人 |
| 内容 | 主题（`platter-theme`）：给六种材料起名。主题只是名字，不影响规则。不调用模型 |
| 设置 | `turnSeconds` 每步时限（默认 0 = 不限时） |
| 牌组 | 60 张，六种材料各 10 张；每张背面是一条计分规则。按人数取用：2 人每种 5 张，3 人 7 张，4 人 9 张，5–6 人 10 张 |
| 摆放 | 洗匀分成三堆，每堆顶上露出规则面；每堆下方摆两张翻成材料面的牌 |
| 回合 | 二选一：拿走一堆顶上的规则牌；或从桌上拿两张材料（只剩一张时拿一张）。空位从上方那堆补牌 |
| 翻牌 | 每回合拿牌之前，可以把自己的一张规则牌翻成它背面的材料，每回合最多一张，不能翻回 |
| 补堆 | 某一堆拿空时，从最多的那堆分一半（底部）过来 |
| 结束 | 三堆和桌面都拿空 |
| 算分 | 每张规则牌按本人的材料数量计分并相加；规则种类：每张加减分、凑组、每 N 张、全场最多/最少、奇偶、总数最多/最少、缺种、六种齐全、达到 N 张的种类数 |
| 秘密信息 | 三堆里除顶牌以外的牌不公开；其余全部公开 |
| 计分 | 结束时每人获得等于自己总分的原始分（负数按 0） |
| 超时 | 自动拿桌上最靠前的两张材料；没有材料则拿一张规则牌 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 不支持，下一局加入 |

主题的选择：开局时在可用主题里取 `weight` 最高的一个；主题不会因为用过而从本场派对里消失。服务器可以通过 `CONTENT_DIR` 目录加载不进仓库的私有主题（见 README）。

**待确认的默认值**：各规则的分值没有经过大量对局验证；是否需要多局制。
