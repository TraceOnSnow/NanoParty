# 拒牌筹码（nothanks）— 规则规格

方向：付筹码拒牌（机制参考：「要么收下负分牌，要么付一个筹码拒绝」的卡牌玩法）。名称、文案为本项目自定。实现：`packages/games/src/nothanks/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–7 人 |
| 内容 | 不使用题库，不调用模型 |
| 设置 | `games` 局数（默认 1）；`turnSeconds` 每步时限（默认 0 = 不限时） |
| 牌组 | 3–35 各一张，洗牌后暗中移除 9 张 |
| 筹码 | 3–5 人每人 11 个，6 人 9 个，7 人 7 个 |
| 回合 | 翻开一张牌。轮到的人二选一：放 1 个筹码在牌上并传给下家（拒绝），或收下这张牌和上面全部筹码，然后翻下一张、仍由 TA 先决定。没有筹码的人只能收下 |
| 结束 | 牌堆翻完 |
| 算分 | 手里的牌是负分：连续的数字只算最小的那张；每个筹码抵 1 分。总分最低的人赢 |
| 秘密信息 | 每人的筹码数只有本人可见，结束时公开；被移除的牌不公开 |
| 计分 | 每局赢家 +3（并列都得） |
| 超时 | 有筹码则自动拒绝，否则收下 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 下一局加入 |

**待确认的默认值**：赢家分值；是否按名次给分。
