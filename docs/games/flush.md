# 压牌出清（flush）— 规则规格

方向：压牌出清（机制参考：「大牌压掉小牌、相同牌结盟」的出清手牌玩法）。名称、文案为本项目自定。实现：`packages/games/src/flush/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–8 人 |
| 内容 | 不使用题库，不调用模型 |
| 设置 | `games` 局数（默认 1）；`turnSeconds` 每步时限（默认 0 = 不限时） |
| 牌组 | 2–20 每个数字 3 张；每人起手 6 张 |
| 回合 | 轮到你时，如果你面前的牌还在，先把它弃掉（它撑过了一整圈）；然后从手里打一张到面前 |
| 压牌 | 一张牌的强度 = 点数 × 桌上同点数牌的张数（相同的牌结盟）。新牌打出后，强度比它低的牌全部被压掉，主人各摸一张 |
| 获胜 | 第一个手牌和面前都没有牌的人 |
| 秘密信息 | 手牌只有本人可见；手牌张数、桌面牌公开 |
| 计分 | 每局赢家 +3 |
| 超时 | 自动打出手里最小的牌 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 下一局加入 |

**待确认的默认值**：牌组分布；摸牌堆抽完后不再摸牌。
