# 谁是卧底（undercover）— 规则规格

首发游戏之一：PRD 中「独立文字提交、统一揭晓、讨论和投票」的网页变体。实现：`packages/games/src/undercover/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–8 人。3–5 人 1 名卧底，6–8 人 2 名卧底 |
| 内容 | 题库类型 `word-pair`：一对相近的词。随机决定哪个是平民词。无 AI 时使用内置题库 |
| 设置 | `games` 局数（默认 3，0 = 不限）；`describeSeconds` 描述时限（默认 120）；`voteSeconds` 投票时限（默认 0 = 不限时，由房主收票） |
| 秘密信息 | 每人只看到自己的词，不被告知身份；他人的词和身份在出局/终局前不出现在其页面与网络数据中 |
| 描述阶段 | 所有在场玩家同时各写一句描述（≤40 字，不能直接包含自己的词）；全部提交前互不可见，收齐后统一公开 |
| 讨论与投票 | 讨论在外部语音进行；每位在场玩家在网页上投一票（不能投自己或已出局者），提交后不可修改；计票前只公开「谁已投票」 |
| 计票 | 全部投完或房主「结束投票并计票」或超时后计票，公开谁投了谁。得票最高者出局并公开身份；平票或无人投票则无人出局 |
| 胜负 | 卧底全部出局 → 平民胜；在场卧底数 ≥ 在场平民数 → 卧底胜；否则进入下一轮描述 |
| 计分 | 平民胜：每位平民 +2（含已出局者）；卧底胜：每位卧底 +4 |
| 终局揭晓 | 公开两个词和所有人的身份；停留在结果页，由房主开始下一局或结束 |
| 超时 | 描述超时：未提交者显示为「没有提交描述」，进入投票；投票超时：按已投的票计票 |
| 跳过 | 房主可在本局结算前「换一组词」：重新发词和身份，本局不计分 |
| 出局者 | 不能再描述或投票，可继续围观公开信息 |
| 中途加入 | 从下一局开始发词；等待期间看不到任何词 |
| 断线 | 身份、词和已提交内容保留；房主可提前公开描述或收票，不会被离线玩家卡住 |
| 重启恢复 | 游戏段暂停，房主继续后当前阶段计时重新开始；词、身份、描述和投票不变，不重新随机 |
| 过期操作 | 每个动作携带阶段计数 `step`，阶段一变旧动作即失效 |

**待你确认的默认值**：卧底人数分档、分值、平票不出局（而不是加赛）、出局即公开身份、不设「白板」角色、描述不做除「包含自己的词」以外的合法性检查。
