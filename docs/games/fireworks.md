# 烟花接龙（fireworks）— 规则规格

方向：看得到别人的牌、看不到自己的牌的合作游戏（机制参考：「靠有限提示把五色烟花从 1 接到 5」的合作卡牌）。名称、文案为本项目自定。实现：`packages/games/src/fireworks/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 2–5 人 |
| 内容 | 不使用题库，不调用模型 |
| 设置 | `turnSeconds` 每步时限（默认 0 = 不限时） |
| 牌 | 5 种颜色 × 10 张（1 三张，2、3、4 各两张，5 一张）= 50 张 |
| 手牌 | 2–3 人每人 5 张，4–5 人每人 4 张 |
| 资源 | 8 个提示，3 条引线 |
| 回合 | 三选一：提示、弃牌、打出 |
| 提示 | 花 1 个提示，对一位队友说一种颜色或一个数字，他手里所有符合的牌都被标出（不符合的牌也因此知道「不是」）。至少要有一张符合 |
| 弃牌 | 弃一张自己的牌（公开），拿回 1 个提示，摸一张。提示已满时不能弃牌 |
| 打出 | 打一张自己的牌：正好是该颜色下一张则接上（接上 5 再拿回 1 个提示）；否则烧掉 1 条引线，牌进弃牌区。然后摸一张 |
| 结束 | 引线烧完（爆炸）；或五色全部接到 5；或牌堆摸完后每人（含摸最后一张的人）再行动一次 |
| 得分 | 五堆最上面的数字之和，满分 25。爆炸记 0 分 |
| 秘密信息 | 自己的手牌只发「被提示过的颜色 / 数字」和「不是什么」；牌的 id 是洗牌后的序号，不含牌面信息；牌堆不发给任何人。结束后公开全部手牌 |
| 计分 | 没有爆炸时：21 分以上每人 +3，16–20 每人 +2，11–15 每人 +1 |
| 超时 | 弃掉最早拿到的那张牌；提示已满时改为给下一位队友一个数字提示 |
| 跳过 | 不支持投票跳过；房主可结束游戏 |
| 中途加入 | 不支持，下一场加入 |

「不许用语音透露别人该出哪张」靠自觉，程序无法约束。

**待确认的默认值**：合作游戏的给分档位；爆炸是否按已接上的分数计而不是 0 分。
