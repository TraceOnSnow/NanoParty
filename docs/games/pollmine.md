# 猜大家选（pollmine）— 规则规格

方向：房间内投票 + 两队轮流猜（机制参考：先秘密投票、再分队猜热门选项的玩法）。题目、名称、规则细节为本项目自定。实现：`packages/games/src/pollmine/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 4–8 人，按加入顺序交替分成红蓝两队 |
| 内容 | 题库类型 `poll`：`{"text": 问题, "options": [4–8 个选项]}`。不调用模型 |
| 数据来源 | **只使用本房间玩家在这一轮的回答**，不使用也不展示任何外部统计 |
| 设置 | `rounds` 轮数（默认 4，0 = 不限）；`voteSeconds` 作答时限（默认 45 秒）；`pickSeconds` 选题时限 |
| 选题 | 每轮由轮流担任的出题人从候选题里选一道，可以换一批，不能自己出题 |
| 作答 | 所有人秘密选一个选项 |
| 翻选项 | 两队轮流（先手每轮交替）翻开一个选项：有人选过 → 本队得「选它的人数」分；没人选过 → 本队失去一条命（每轮 2 条）。没命的队伍被跳过 |
| 一轮结束 | 有人选的选项全部翻出，或两队都没命，或房主直接结算 |
| 秘密信息 | 谁选了什么始终不公开；未翻开选项的人数在结算前不公开 |
| 计分 | 每轮分数高的队伍每人 +2；打平（且不是 0:0）每人 +1 |
| 超时 | 选题超时用第一道候选；作答超时以已有回答进入翻选项（没人作答则本轮不计分） |
| 跳过 | 作答阶段可投票跳过这道题 |
| 中途加入 | 下一轮加入人少的一队 |

**待确认的默认值**：每轮的命数；是否允许出题人自己出题（需要多选项的自拟题界面）。
