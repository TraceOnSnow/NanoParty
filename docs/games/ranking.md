# 排排座（ranking）— 规则规格

首发游戏之一，方向：合作排序（机制参考：按秘密数字回答情境、由队长排序的合作玩法）。名称、内容与分值为本项目自定，不使用任何商业作品的名称或素材。实现：`packages/games/src/ranking/game.ts`。

| 项目 | 规则 |
| --- | --- |
| 人数 | 3–8 人，合作 |
| 内容 | 题库类型 `scale-scenario`：情境 + 低端描述 + 高端描述 |
| 设置 | `rounds`（默认 4）；`writeSeconds`（默认 120）；`orderSeconds`（默认 120） |
| 队长 | 每轮一名，担任次数最少者优先 |
| 选题 | 每轮正式开始前，由本轮队长从 3 个候选情境里选一个；可以不限次数地换一批，或自己出一个（保存进题库）。换一批不消耗题库，只有确认的题才计为已用；选题阶段不算回合开始，不能投票跳过。AI 交来的候选题会替换当前候选，若本轮已开始则留到下一轮。选题时限 `pickSeconds`（默认 60 秒），超时用第一道候选。出题人也照常参与本轮 |
| 秘密信息 | 非队长各得一个互不相同的 1–10 的数字，只有本人可见，揭晓前不出现在他人页面与网络数据中 |
| 作答 | 非队长各写一个回答（≤40 字，不能含数字）；全部提交前互不可见 |
| 排序 | 回答公开（乱序，数字保密），队长提交从低到高的顺序 |
| 计分（团队） | 排反的「对数」为 0：全员 +3；为 1：全员 +1；否则 0。回答不足两个不计分 |
| 超时 | 作答超时：用已有回答进入排序；排序超时或队长不在：按展示顺序结算 |
| 跳过 | 揭晓前可投票跳过，不计分 |
| 中途加入 | 从下一轮开始参与；等待期间看不到秘密信息 |
| 断线 | 身份与已提交内容保留；每个阶段都有超时或房主推进入口，不会被离线玩家卡住 |
| 重启恢复 | 游戏段暂停，房主继续后当前阶段计时重新开始；已发的秘密和已提交内容不变 |
| 过期操作 | 每个动作携带阶段计数 `step`，阶段一变旧动作即失效 |

**待确认的默认值**：分值；是否改为「错一个扣一条命」的整段合作制；数字范围。
